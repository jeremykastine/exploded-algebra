# Exploded Algebra repository instructions

Whenever a change affects any part of the Exploded Algebra app, update the visible
`Last updated` line at the top of `index.html` in the same commit. Use the current
date and time in the `America/New_York` time zone, include `EDT` or `EST` in the
visible text, and update the `<time>` element's machine-readable `datetime` value.
